## 0.1.0

Initial release.

- Compose searchable menus with command inputs, lists, groups, and custom items.
- Filter and rank commands with fuzzy search and keyword aliases.
- Navigate and activate commands with keyboard, pointer, and touch input.
- Keep soft-keyboard Search activation compatible with Flutter stable, including disabled and context-dependent actions.
- Control query and selection state, remap shortcuts, and present modal menus.
- Build fixed-height virtual lists from a complete item catalog.
